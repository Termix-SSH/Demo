# Changelog

## 1.0.0

### Added

- A full screen layout for a TV or spare monitor, with no sidebar, tab bar or editing
- Cycles through Homepage, Uptime, Host Status and Network Topology, skipping views that are not installed
- A host status board with big online and offline counts, grouped by folder
- Hidden toolbar and keyboard keys to pause, go back, go forward, go full screen, change layout or sign out
- Settings for how long each view shows and which views are on
- Keeps the screen awake and hides the cursor while nobody moves the mouse
