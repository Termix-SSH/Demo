# Changelog

## 1.2.0

### Added

- High Contrast Dark and High Contrast Light themes with strong text, borders and focus outlines
- Color Blind Dark and Color Blind Light themes that show good as blue and bad as orange instead of green and red

## 1.1.0

### Changed

- Built for plugin API 2, so it no longer needs Run without isolation turned on
- Needs Termix 26.11.2 or newer

## 1.0.1

### Changed

- Borders are solid colors, so they look the same on every surface

## 1.0.0

### Added

- The Termix color themes as a plugin: light, dark, Dracula, Catppuccin, Nord, Solarized, Tokyo Night, One Dark and Gruvbox
